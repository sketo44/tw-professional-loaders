# لودرات احترافية لسلة

حزمة مكوّنات لسلة تضم 20 حركة تحميل قابلة للاختيار من إعدادات المكوّن.

## خصائص التاجر

- اختيار واحد من 20 تصميمًا.
- إظهار أو إخفاء نص التحميل وتعديله.
- خلفية تلقائية أو فاتحة أو داكنة أو شفافة.
- ضبط ارتفاع مساحة العرض من 200 إلى 700 بكسل.
- يمكن إضافة المكوّن أكثر من مرة في الصفحة لاستخدام تصاميم مختلفة.

## التطوير والاختبار

```bash
pnpm install
pnpm test
pnpm dev
```
